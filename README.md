## 🚀 Featured Projects

### 🔹 [Smart Pipeline API](https://github.com/soumyadipgiri/smart-pipeline)
> FastAPI · DuckDB · Pandas · Claude API · Pydantic v2 · pytest

Full ETL backend that ingests CSV uploads, cleans data (null handling, type coercion, deduplication), and stores results in DuckDB with a two-layer schema. Includes an **AI agent endpoint** that translates plain-English questions into SQL via Claude, executes them, and returns the generated SQL + results. 5 unit + integration tests, structured logging, and a pipeline run history table.

---

### 🔹 [Bank Management System](https://github.com/soumyadipgiri/bank-management)
> Python · OOP · File I/O

Console-based banking system with account creation, deposits, withdrawals, and balance checks. Built as a deep-dive into OOP patterns and data persistence — classes separate account logic from the menu layer, file I/O handles persistence without a database.

---

### 🔹 [Secure Password Generator](https://github.com/soumyadipgiri/password-gen)
> Python · secrets module · CLI

CLI tool for generating cryptographically secure passwords with configurable length and character sets. Uses Python's `secrets` module over `random` — a deliberate choice for actual security.
